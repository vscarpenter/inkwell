# Inkwell 3.5.0 Adoption Release Implementation Plan

**Goal:** Ship the approved repository-review recommendations as a coherent 3.5.0 release that is easier to evaluate, install, use correctly, and keep internally consistent.

**Architecture:** Preserve the zero-runtime CSS path. Add one optional dependency-free interaction file, one machine-readable component manifest with a generated human reference, and maintainer-only Node/Playwright verification. Generated outputs are checked into the repository and CI rejects drift.

**Spec:** `docs/specs/2026-08-27-v3.5-adoption-release-design.md`

## Task 1 — Lock the contract with failing checks

- [x] Add `scripts/check-system-contract.mjs` for versions, file mirrors, manifest selectors, HTML semantics/metadata, form error relationships, local assets, Tailwind aliases, and known stale claims.
- [x] Add `playwright.config.mjs` and `tests/browser-smoke.spec.mjs` for interaction, theme/palette, accessibility-contract, and mobile-overflow smoke coverage.
- [x] Run both against the pre-3.5 tree and preserve the failures as the implementation checklist.

## Task 2 — Publish the additive API

- [x] Add the `.disclosure` native details component and coarse-pointer target sizing.
- [x] Add the preferred Tailwind `border-inkwell` alias while retaining the deprecated `border-hair` alias.
- [x] Add `inkwell-interactions.js` for tabs, carousel, and declarative dialog behavior.
- [x] Replace example-only duplicate interaction code with the shared module.

## Task 3 — Build the adoption reference

- [x] Route the gallery, docs, README, and agent instructions to the reference.
