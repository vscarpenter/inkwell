Editorial sample

Design notes for calm product interfaces.

This article layout uses Inkwell typography, link styling, compact navigation chips, and dark callouts for documentation or product essays.

01

Principles

Inkwell keeps the system quiet so content and workflow state carry the page. It favors editorial headings, understated surfaces, and a single accent color.

Use --paper for panels, --ivory for the page, and --accent only where users need a strong interaction cue.

Rule
If a value exists in tokens.css, reference the token instead of hardcoding a matching color or spacing value.
02

Application

Long-form pages should use narrow reading widths, generous section spacing, and links with the built-in Inkwell underline style.
