# Product purpose

Inkwell supplies copyable, dependency-free CSS and optional native-browser interactions for product interfaces and technical/editorial pages.

## Primary user

Developers and coding agents assembling accessible product and editorial interfaces for desktop and mobile browsers from the documented HTML contract.

## Principles

1. Usable states outrank decorative subtlety: functional boundaries, focus, and selection must remain perceivable.
2. Keep the letterpress identity: 1.5px frames, serif headings, platform fonts, flat surfaces, and one brand accent.
3. Structure stays shared; palettes override brand tokens rather than duplicating components.
4. Native semantics and progressive enhancement keep the consumer dependency-free.
5. Components must survive narrow containers, enlarged text, and user display preferences.

## Success metric

A consumer can copy documented markup, link the CSS, and operate its controls using touch or keyboard in light, dark, and user-selected contrast modes without content clipping.

## Out of scope

- Framework wrappers, package metadata, and consumer build tooling.
- Webfonts or a new brand direction.
- Publishing or deploying this review.
